Sum up 25 November's world news in one image — a make.fun bounty entry.

`main.py` draws the newspaper front page **THE GLOBAL HERALD** (Wednesday 25 November 2026) with PIL and writes it deterministically to `entry.png` (1024×683). Five verified stories from 25 Nov 2026:

1. Kyiv strikes Russian ships in two seas
2. Houthi missile hits Riyadh's tallest tower
3. Microsoft declares 'code red' (global outage)
4. NATO vows space defence
5. China launches Shenzhou-24 (first Pakistani astronaut to Tiangong)

Run it:

```sh
python3 main.py   # writes entry.png, byte-identical on every run
```
